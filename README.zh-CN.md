# AZA-STT

[繁體中文](README.md) | [简体中文](README.zh-CN.md)

AZA-STT 是一个 Windows 语音输入工具。把光标放在任何可以输入文字的位置,按下录音键开始说话,程序就会把语音整理成文字并自动粘贴。

它支持简体中文与繁体中文口述内容,包含自然分句、半角英文标点、段落切分,以及常见 AI 与科技名称的拼写修正。程序平时会待在 Windows 右下角系统托盘,不会一直占用桌面空间。

## 使用前请注意

AZA-STT 高度依赖 Groq API。本项目只提供本机端录音、文字整理与操作界面,本身不提供语音识别服务。使用时必须准备自己的 Groq API key,并且能正常连接 Groq 服务。

Groq 目前提供的免费额度、模型、API 规格与服务可用性均由 Groq 决定,本项目无法保证这些条件永久不变。如果未来 Groq 调整免费额度、停止相关模型、改变 API 规格或限制此类用途,AZA-STT 可能需要改用其他语音识别 API 或本地模型。在完成替代方案之前,程序可能暂时无法使用；如果没有合适的替代来源或后续维护,本项目也可能停止运行。

## 主要功能

- 使用 Groq Whisper 进行语音识别
- 可切换简体中文或繁体中文 UI 与输出,第一次启动会根据 Windows 语言自动选择
- 只转换字形,不会擅自把“脚本”改成“指令码”等不同词汇
- 统一使用半角英文标点,并在标点后保留一个空格
- 根据说话停顿自然分句,每五句自动换段
- 自动修正 Groq、Gemini、ChatGPT、Claude Code、NVIDIA、OpenAI、GitHub Copilot、Codex、quota 等科技名称
- 识别完成后直接粘贴到当前输入位置
- 可自行更换键盘按键或鼠标侧键,并选择三种录音方式
- 可从系统托盘选择麦克风,指定设备失效时会自动改用其他可用设备
- 常驻 Windows 右下角系统托盘,可随时查看状态、修改设置或退出
- 短录音直接上传 WAV,较长录音会自动使用无损 FLAC 压缩,不需要另外安装 FFmpeg
- 识别失败时会自动切换模型或备用 API key

## 如何使用

### 1. 下载并启动

从 [GitHub Releases](https://github.com/ReaperTw/AZA-STT/releases/latest) 下载最新版本。

- 想直接使用:下载 `AZA-STT.exe`
- 想连同 README 与辅助工具一起保存:下载完整 ZIP 并解压

下载后双击 `AZA-STT.exe` 即可启动,不需要另外安装。

### 2. 设置 Groq API key

第一次启动时,AZA-STT 会根据 Windows 语言选择简体或繁体界面,并自动打开设置窗口。

1. 如果还没有 API key,点击 **打开 Groq API Keys** 前往 [Groq 官方申请页面](https://console.groq.com/keys)。
2. 将取得的 key 粘贴到设置窗口。
3. 点击 **保存**。

设置完成后,AZA-STT 会缩到 Windows 右下角系统托盘继续运行。

### 3. 开始语音输入

1. 把光标放在想输入文字的位置。
2. 连续按两次默认的 **Menu 键** 开始录音。
3. 说完后再按一次相同按键。
4. 等待识别完成,文字会自动粘贴到光标位置。

录音时会出现红色圆球,识别时会变成橙色,完成后显示绿色并自动消失。圆球消失不代表程序已经关闭,AZA-STT 仍会留在系统托盘等待下一次使用。

### 4. 设置录音控制与麦克风

1. 在 Windows 右下角找到 AZA-STT 图标。
2. 点击右键并选择 **设置录音控制**。
3. 点击 **按下新的键盘键或鼠标侧键**,再直接按一次想使用的按键。
4. 选择录音方式。
5. 点击 **保存**。

键盘上的一般按键、功能键、Ctrl、Shift、Alt、空格键,以及常见的两颗鼠标侧键都能使用。选中的按键会被 AZA-STT 拦截,所以原本功能可能无法使用。

录音方式共有三种:

- **连续按两次开始,按一次停止**:默认方式,可减少误触
- **按一次开始,再按一次停止**:最快速的开关方式
- **按住时录音,松开停止**:类似对讲机

若要指定录音设备,请在相同的右键菜单中选择 **选择麦克风**。一般情况建议保留“系统默认”；如果指定的 USB 或蓝牙麦克风被拔除或暂时失效,AZA-STT 会在下一次录音时重新扫描设备并自动改用其他可用麦克风。

### 5. 语言、其他设置与退出

在右下角 AZA-STT 图标点击右键,还可以:

- 切换 **简体中文 / 繁體中文**；UI、Groq 识别提示与输出会一起切换
- 选择或重新扫描麦克风
- 重新输入 Groq API key
- 打开 Groq API Keys 网页
- 完整退出 AZA-STT

双击系统托盘图标可以查看当前状态、录音按键与操作方式。

## 常见问题

### 录音圆球不见了,程序是不是关闭了?

不是。圆球只在录音与识别期间出现。平时请在 Windows 右下角系统托盘寻找 AZA-STT 图标。

### 双击 EXE 没有出现新窗口?

AZA-STT 同一时间只会运行一个实例。它可能已经在系统托盘运行,因此不会再打开第二个实例。

### 键盘没有 Menu 键怎么办?

从系统托盘 AZA-STT 图标的右键菜单更换录音控制即可。可以改用其他键盘按键或鼠标侧键。

### 如何更换 Groq API key?

在系统托盘 AZA-STT 图标点击右键,选择 **重新输入 Groq API key**。保存后立即生效。

## 隐私与安全

AZA-STT 本身在你的 Windows 电脑上运行,没有自己的账号系统或中转服务器。

- Groq API key 只会存储在这台电脑的 `%LOCALAPPDATA%\AZA-STT\dictate_settings.conf`
- 录音停止后,音频会直接发送到 Groq 语音 API 进行识别
- 临时 WAV 或 FLAC 音频会在处理完成后删除
- 识别结果会暂时放入 Windows 剪贴板,用于自动粘贴
- 本地运行日志不会保存完整转录稿或 API key
- 程序没有加入广告、用户追踪或遥测服务

完整源代码公开在这个 Repository。如果对程序行为有疑问,可以直接检查 [`groq_dictate.py`](groq_dictate.py),交给熟悉 Python 的人查看,或使用 AI 代码工具协助检查后再运行。
